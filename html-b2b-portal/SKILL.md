# B2B 门户设计 Skill

## 1. 定位与适用边界

面向**企业用户（采购商 / 供应商）**的 B2B 门户与产业互联网平台设计，输出零构建、可直接浏览器打开的响应式 HTML 单文件原型。

- **适用**：大宗商品交易平台、工业品 / MRO 企业采购、产业互联网门户、供应链协同平台、产地直供门户、找货 / 询价 / 行情类页面
- **不适用**：B2C 零售商城、品牌营销官网、纯后台管理系统（应改用对应设计规范）

## 2. 核心设计原则（不可妥协）

1. **商业严谨**：稳重专业，主色低饱和，避免大面积高饱和与娱乐化插画。
2. **效率优先**：用户以扫描为主，搜索 → 筛选 → 询价必须 3 步内可达。
3. **F 型动线**：首屏依次承载 搜索 / 行情 / 核心入口，主 CTA 唯一且醒目。
4. **信任可见**：认证体系、交易保障、成交数据、资质信息在卡片级可见。
5. **行业适配**：行业关键指标与术语必须进入筛选器、卡片标签和文案。
6. **多端一致**：移动优先，手机 / 平板 / PC 三端断点全覆盖。

### 2.1 视觉基调：工业级数据终端（不要退回普通企业官网）

目标观感是**「数据感」而非「官网感」**——用户第一眼要觉得这是个专业交易终端，不是一张公司简介页。判断标准很直接：把截图缩小到拇指大小，还能不能看出「这里有实时数据」？

**核心手法：深色承载数据，浅色承载商品。**

| 层次 | 做法 |
|------|------|
| 节奏 | 深浅交替，不要一片白。首页走 **深 Hero → 浅内容 → 深驾驶舱 → 浅内容 → 深货源网络 → 浅内容 → 深页脚** |
| Token | 圆角阶梯 8→28px；阴影 6 档多层 + 彩色光晕（用 `--primary-rgb` 分量变量让光晕跟随行业主色）；中性文字三阶 |
| 深色面板 | `--panel` 系列深色 + 玻璃拟态 + 网格底 + 极光光斑；行情/数据/物流放这里 |
| 浅色区 | 纯白卡 + 大留白 + 主题渐变图标；商品、服务、资讯放这里 |
| 数据可视化 | 行情不能只是一行小字。要有大数字、涨跌色、sparkline、走势图、热度条 |
| 动效 | 见 spec §5.1。粒子 / 视差 / 3D 倾斜 / 光效是**标配**，但必须守降级红线 |

**四条最容易踩的返工点**

1. 只改颜色不算换行业——`THEME` 四个色值必须整套换（含 `primaryLight / primaryDark`），否则深色区会脏。
2. 大标题别用 `background-clip:text` 做通栏渐变：渐变作用于整个 h1 盒子，橙色会落在文字右侧的空白处而不是字上。用**白色主标题 + 强调色词**，冲击力更强且不依赖盒子宽度。
3. 涨跌色固定为**涨红跌绿**（中国市场惯例），深色底上用提亮版 `--up-on-dark / --down-on-dark`，不要直接拿浅色底的值。
4. 动效失效时内容必须完整可读；首屏关键状态类写在自己的 `<style>` 里，不交给 CDN 运行时生成（细则见 spec §5.1）。

## 3. 标准工作流（5 步）

### Step 1 · 行业定档 → 读行业画像

打开 `references/industry-profiles.md`，定位对应行业，确定：**主色体系、一级类目树、关键指标字段、计价 / 交易习惯、对标平台、Mock 数据样例**。

- 用户未指定行业：根据其经营品类**主动追问一次**，不要自行假设。
- 多行业综合平台：使用 `generic` 中性主题（阿里橙 `#FF6A00`）。
- 行业不确定时用画像中的"适配信号"（品类关键词）反推，并向用户确认。

### Step 2 · 页面选型 → 读布局规范

打开 `references/page-layouts.md` 对应章节：

| 用户诉求关键词 | 产出页面 | 布局文件章节 |
|----------------|----------|--------------|
| 门户 / 首页 / 平台长什么样 | 门户首页 | §1 首页 |
| 找货 / 货源 / 产品列表 / 搜索结果 | 产品列表页 | §2 列表页 |
| 产品 / 商品详情 / 参数 | 产品详情页 | §3 详情页 |
| 询价 / 采购需求 / RFQ / 求购 | RFQ 询价页 | §4 RFQ |
| 店铺 / 供应商主页 | 供应商店铺页 | §5 店铺页 |

> 首页 / 列表页 / 详情页在 `assets/` 均有整页模板可直接复制改造，不必从零拼装；模板的行业适配点见文件头注释。

### Step 3 · 组件装配 → 读组件库

打开 `references/component-library.md`，按布局逐区块选取组件并复制 HTML 片段。行情类组件（滚动条 / 行情卡 / 走势图）为大宗商品门户必选；工业品 MRO 门户可弱化行情、强化品牌筛选与协议价。

**动效层（§F）是可选增强，不是必装件**。要做"惊艳"的门户首页时，按 §F 取用：3D 全息地球、3D 倾斜卡、滚动视差、极光/聚光/流光边框、粒子网络、错峰进场、滚动进度。两条硬约束先记住：
- 必须整段照抄 §F0（环境探测 + 减动降级），否则机检直接判 ERROR；
- 粒子网络（F4）与全息地球（F6）**只建议首页各用一次**，同页重复会互相打架并拖垮体积预算；列表页 / 详情页取 F1 / F2 / F5 / F7 即可。

### Step 4 · 数据填充 → 按 Mock Schema 造数

打开 `references/html-prototype-spec.md` §4 Mock 数据 Schema：
- 所有列表数据用 JS 数组 + `render` 函数渲染，**禁止把卡片硬编码成静态 HTML**。
- 字段名、数值单位、价格区间、涨跌方向必须符合行业画像，术语拿不准时查 `references/glossary.md`。
- 数据量：首页 8-15 条、列表页 12-24 条、供应商 4-8 家。

### Step 5 · 质量门禁 → 先机检，再人工

```bash
python scripts/check_prototype.py 交付文件.html
```

机检 0 ERROR 后，再逐项过本文件 §7 质量门禁清单。未通过项当场修复，不要把问题留给用户。

## 5. 门户首页模块速查（完整线框见 page-layouts.md §1）

标准顺序（可按行业裁剪，不可乱序）：

```
顶部通栏(32px) → 粘性头部(Logo+搜索+询盘/购物车/消息,64-72px)
→ 主导航(全部分类+一级入口,44-48px)
→ Hero[左:分类导航 200-240px | 中:Banner 轮播 | 右:快捷入口]
→ 行情滚动条 → 采购/供应专区(Tab) → 热卖产品网格(4-5列)
→ 认证供应商(4列) → 价格走势图(Chart.js) → 平台服务优势(5列)
→ 行业资讯(3列) → 页脚(多栏链接+联系方式+备案)
```

裁剪规则：
- **行情导向行业**（钢铁 / 矿石 / 有色 / 化工 / 能源 / 农产品）：保留行情滚动条 + 走势图，置于产品区之前。
- **MRO / 工业品**：用"品牌专区 + 品类专场"替代走势图；行情条可缩为一行公告。
- **生鲜类**（水果 / 海产 / 冻品 / 生猪）：强化产地 / 冷链 / 检疫标签，Banner 主打"产地直供 / 当日达"。

## 7. 质量门禁（交付前：先机检，再逐项自检）

**功能**
- [ ] 搜索可提交（回车 + 按钮），占位文案含行业品类词
- [ ] 分类导航可展开 / 收起，移动端为抽屉
- [ ] 行情滚动条自动滚动且涨跌色 / 箭头正确
- [ ] 走势图（如保留）正常渲染，坐标轴单位正确
- [ ] 询价 / 加入询盘按钮有点击反馈，询盘角标可联动

**行业适配**
- [ ] 主色与行业速查表一致（或经用户确认的定制色）
- [ ] 卡片标签含该行业 ≥3 个关键指标
- [ ] 单位正确（吨 / kg / 件 / 立方米 / 张），价格带符合行业量级
- [ ] 术语使用经 glossary 核对，无生造词

**视觉与动效**
- [ ] 深浅节奏成立（首页不是一片白）；行情 / 数据 / 物流确实放在深色区
- [ ] 行情有可视化：大数字 + 涨跌色 + sparkline / 走势图 + 热度条，不是一行小字
- [ ] 主色整套换过（含 `primaryLight / primaryDark`），深色区不发脏
- [ ] **动效降级齐全**：有 `@media (prefers-reduced-motion:reduce)`；**无 JS 时内容完整可读**（进场初始态不得直接写在 CSS 里）；canvas 离屏暂停、DPR 封顶 2；指针效果仅在精确指针设备启用
- [ ] **首屏关键状态**（轮播显隐、指示点）用本文件自己的类，不依赖 CDN 运行时生成工具类——漏生成会让多张幻灯片叠成重影
- [ ] 动效只改 `transform / opacity`；单页 canvas ≤2 且常驻 rAF ≤2
- [ ] 大标题不用通栏 `background-clip:text` 渐变（橙色会落在文字右侧空白处，不在字上）

**工程与体验**
- [ ] 单文件、零构建、无控制台报错；外部资源仅 CDN；体积符合 spec §7 预算（首页 ≤120KB / 其他 ≤60KB，未 gzip）
- [ ] 三端断点不破：手机 <640 / 平板 640–1023 / PC ≥1024（Tailwind 默认断点，见 spec §1.4）
- [ ] **`:root` 已完整粘贴 spec §2 变量**（尤其 `--success / --warning / --error / --secondary-text`），全文件无悬空的 `var(--x)`（缺失变量不报错但样式静默失效）
- [ ] **图标全部为 Font Awesome 6 名称**，无 `fa-star-o` 等 v4 语法
- [ ] **语义色对比度**达 spec §6 规则：Toast / 角标的前景与底色成对，无白字压 `#FAAD14`、`#52C41A`；`--secondary` 未直接用作文字色（小字一律用 `--secondary-text` / `--secondary-on-dark`）
- [ ] 列表由 JS 数据渲染，非硬编码
- [ ] 可点击元素有 hover / active 态；图片区有占位，不出现裂图
- [ ] 首屏无横向滚动条；正文与操作文案 ≥12px（角标徽标 10–11px 例外，见 spec §9-10）；按钮 ≥32px 高
- [ ] 不含真实个人隐私 / 真实企业机密数据，一律用虚构样例

