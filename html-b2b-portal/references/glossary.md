# 行业术语词典（Glossary）

> 用法：文案、字段命名、筛选项命名时查阅。格式：术语 —— 简释（场景）。
> 原则：原型文案宁可用"规格/牌号"等通用词，也不要生造行业术语。

## 1. 通用交易与平台模式

| 术语 | 简释（场景） |
|------|--------------|
| 大宗商品 | 可进入流通、非零售、大批量买卖的标准化物质商品（平台定位） |
| 标品 / 非标品 | 统一规格质量的产品 / 按需定制的产品（分类、搜索） |
| 现货 / 期货 / 预售 | 即提库存 / 未来交割 / 未到货先售（交易类型标签） |
| 撮合交易 | 平台作中介匹配买卖双方（平台模式说明） |
| 挂牌交易 | 卖方发布商品与价格等买方摘牌（交易方式） |
| 竞价 / 拍卖 | 多方出价，按规则价高或价低者得（专场活动） |
| 招投标 | 买方发标、供应商投标（企业采购、阳光采购） |
| 集采 | 多买家联合采购换价格优势（专区入口） |
| 长协 | 长期供应协议，锁量锁价或约定机制（合同类型） |
| 点价 | 以约定时段期货价为基准确定现货价（有色/大宗定价） |
| 基差 | 现货价 − 期货价（行情分析、套保） |
| 含税价 / 不含税价 | 是否含增值税，B2B 卡片默认应标注（价格口径） |
| 出厂价 / 到站价 / 自提价 | 运费责任分界（报价口径） |
| 询盘 / 报盘 | 买方询价 / 卖方报价（IM 与表单） |
| MOQ | 最小起订量（工业品卡片） |
| SKU | 最小库存单元（规格 / 型号颗粒度） |
| 账期 | 约定延期付款天数，如月结 30 天（企业交易条款） |
| 先行赔付 | 平台对纠纷先行垫付的保障服务（信任组件） |

## 2. 钢铁

| 术语 | 简释 |
|------|------|
| 牌号 | 钢材品种代号，如 HRB400E、Q235B、Q355B |
| 规格 | 直径×长度或厚×宽，如 Φ20×9m、4.75×1500 |
| 理计 / 理重 | 按理论重量计价结算 |
| 过磅 / 磅计 | 按实际称重结算 |
| 定轧 | 按需定制轧制（服务标签） |
| 螺纹钢 | 热轧带肋钢筋，建筑主材 |
| 盘螺 / 高线 | 盘卷交付的螺纹钢 / 盘条 |
| 热卷 / 冷卷 | 热轧 / 冷轧板卷 |
| 镀锌板 | 表面镀锌防锈板材 |
| 中厚板 | 厚度较大的钢板（工程/机械） |
| H 型钢 | 截面呈 H 的型材 |
| 不锈钢 304/316 | 奥氏体不锈钢牌号 |
| 公差 | 实际尺寸相对标准的允许偏差 |
| 一单一议 | 按订单单独议价（大宗批量） |

## 3. 矿石

| 术语 | 简释 |
|------|------|
| TFe | 全铁含量百分比，铁矿核心品位指标 |
| 品位 | 有用成分含量，决定价格 |
| A/S | 铝硅比，铝土矿核心指标 |
| 粒度 | 颗粒大小，如 10-40mm、-10mm 粉矿 |
| 干吨 / 湿吨 | 扣除水分计量 / 含自然水分计量 |
| PB 粉 | 皮尔巴拉混合粉矿，主流铁矿品种 |
| 块矿 / 球团 | 入炉块状矿 / 人造球状富矿 |
| 港口现货 | 转运港口堆场可提的现货 |
| 水分 | 矿石含水比例，影响干吨结算 |

## 6. 能源

| 术语 | 简释 |
|------|------|
| 收到基低位发热量 | 实际使用状态下单位重量有效热值（kcal/kg） |
| 大卡 | 热值口语单位，如 5500 大卡煤 |
| 灰分 | 完全燃烧后残渣占比 |
| 全硫 | 硫元素总含量，环保指标 |
| 挥发分 | 受热挥发出的可燃气体比例 |
| 坑口价 / 港口价 | 煤矿场地交货 / 中转港交货价 |
| 长协煤 | 中长期协议煤，价格机制与市场煤不同 |
| 主焦煤 / 喷吹煤 | 炼焦核心煤种 / 高炉喷吹用煤 |
| LNG / CNG | 液化 / 压缩天然气 |
| 国六柴油 | 符合国六排放标准的车用柴油 |

| 尿素 | 主流量氮肥，含氮约 46% |
| 磷酸二铵（DAP） | 主流高浓度磷肥 |
| 氯化钾 / 硫酸钾 | 钾肥两大品种 |
| 颗粒 / 粉状 | 肥料形态，影响施用 |
| 基肥 / 追肥 | 播种前底肥 / 生长期补肥 |

## 8. 农产品粮油

| 术语 | 简释 |
|------|------|
| 一等 / 二等 | 粮食国家质量等级 |
| 容重 | 单位容积重量（g/L），定等核心指标 |
| 水分 / 含水率 | 含水百分比，影响储存与结算 |
| 不完善粒 | 虫蚀、霉变、破损等颗粒占比 |
| 新陈粮 | 当年粮 / 往年库存粮 |

| 油粕 | 油料压榨产物：油脂与饼粕 |

## 9. 水果生鲜

| 术语 | 简释 |
|------|------|
| 果径（#） | 果实直径毫米数，如 80# |
| 糖度（°Brix） | 可溶性固形物含量 |
| 硬度 | 果实抗压力，判断成熟度与耐储性 |
| 特级 / 一级 | 商品分级 |
| 一件代发 | 产地直发终端消费者的履约模式 |
| 筐 / 件 | 批发市场标准包装单位 |
| 产季 | 集中上市期，决定供应与价格 |
| 糖心 / 表光 | 品质卖点描述（苹果等） |

## 13. 工业品 / MRO

| 术语 | 简释 |
|------|------|
| MRO | 非生产性物料：维护、维修、运营用品 |
| 协议价 | 与大客户约定的合同价，前台不展示或仅会员可见 |
| 品牌授权 | 正规经销授权证明 |
| 型号 | 厂商产品编号，工业品搜索主词 |
| 参数选型 | 按技术参数（电压/功率/尺寸）筛选 |
| 起订量 MOQ | 最小订货数量 |
| 增值税专票 | 13% 增值税专用发票 |
| 长尾商品 | SKU 多、单 SKU 销量低的商品 |
| 寄售 / VMI | 供应商管理库存模式 |
