# 行业画像（Industry Profiles）

> 用法：Step 1 只读目标行业小节。每个画像含：适配信号 / 配色 / 类目树 / 卡片与筛选指标 / 计价交易习惯 / 对标平台 / Mock 数据样例。
> 行情配色全行业统一：涨 `#E53E3E`、跌 `#38A169`、平 `#999999`。

**画像通用模板**

```text
适配信号：用户提到的品类关键词（用于反推行业）
配色：主色 / 浅底 / 深色变体
类目树：一级类目 → 代表二级
卡片指标：产品卡必展示的规格标签
筛选指标：列表页筛选器字段
交易习惯：计价单位 / 结算方式 / 交付特点
对标平台：风格与信息架构参考
Mock 样例：1 条产品 + 1 条行情
```

## 1. 钢铁 `steel`

- **适配信号**：螺纹钢、热卷、板材、钢管、H 型钢、不锈钢、钢厂、理重、过磅
- **配色**：`#1E3A5F` 钢铁蓝 / 浅底 `#E8EEF4` / 深色 `#0F1D2F`；辅助强调 `#FF6A00`
- **类目树**：
  - 建筑钢材：螺纹钢、盘螺、高线、圆钢
  - 板材：热轧板卷、冷轧板卷、镀锌板、中厚板、彩涂板
  - 管材：无缝管、焊管、镀锌管、方矩管
  - 型材：H 型钢、工字钢、角钢、槽钢
  - 不锈钢：304/316 卷板、不锈钢管、不锈钢棒
  - 优特钢：合结钢、齿轮钢、弹簧钢
- **卡片指标**：牌号（HRB400E / Q235B）、规格（Φ20×9m / 4.75×1500）、钢厂（沙钢 / 首钢 / 宝武）、理计 / 过磅
- **筛选指标**：品类、牌号、规格、钢厂、仓库城市、计重方式
- **交易习惯**：元/吨；理计（理论重量）或磅计（过磅）；多为含税价；现货当日可提，支持定轧；批量 ≥ 整包车板（约 30-40 吨起优）
- **对标平台**：找钢网、上海钢联 Mysteel、钢银电商、欧冶云商
- **Mock 样例**
  - 产品：`螺纹钢 HRB400E Φ20×9m · 沙钢 · 理计 · ¥3,650~3,720/吨 · 上海宝山库`
  - 行情：`螺纹钢 HRB400 4500 ↑ +2.0%（+88 元/吨）`

- **适配信号**：铁矿、粉矿、块矿、球团、TFe、品位、铝土矿、锰矿、铬矿、港口现货
- **配色**：`#0F4C81` 矿石蓝 / 浅底 `#E8F0F8` / 深色 `#072840`
- **类目树**：

  - 锰矿：加蓬锰矿、南非锰矿
  - 铬矿：南非铬矿、土耳其铬矿

- **卡片指标**：TFe 品位（62%）、A/S 铝硅比、粒度（10-40mm / 粉矿 -10mm）、水分

- **对标平台**：欧冶云商、Mysteel 矿石频道、钢联矿端
- **Mock 样例**
  - 产品：`PB 粉矿 TFe 61.5% · 粒度 -10mm · 日照港现货 · ¥890/湿吨`
  - 行情：`铁矿石 62% 指数 950 → 0.0%`

## 主题切换实现要点

1. 所有颜色通过 `:root` CSS 变量注入（变量名固定：`--primary / --primary-light / --primary-dark`），换行业只改变量值。
2. 强调色默认 `#FF6A00`，当主色本身为橙色系（energy / generic）时强调色改用主色深色变体，避免同色失效。
3. Banner 渐变统一为 `主色 → 深色变体 120deg`，行业切换无需重画。
4. 行情三色为语义色，**不随主题变化**。
