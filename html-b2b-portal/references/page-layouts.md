# 页面布局规范（Page Layouts）

> 用法：Step 2 只读目标页面章节。所有页面共享：容器 1200px、断点 576/768/992/1200、页面灰底 `#F8F8F8` + 白色卡片。

## 目录

1. 门户首页
2. 产品列表页
3. 产品详情页
4. RFQ 询价页
5. 供应商店铺页

### 全局尺寸速查

| 元素 | PC | 移动 |
|------|----|------|
| 容器 | max 1200px，左右 16px | 100%，左右 12px |
| 顶部通栏 | 32px | 隐藏副信息，仅留登录 |
| 头部 | 64-72px | 56px（搜索换行或下钻） |
| 主导航 | 44-48px | 汉堡 + 横滑 |
| 卡片圆角 | 8px | 6px |
| 区块间距 | 24px | 16px |

## §1 门户首页

### 1.1 完整线框

```
┌──────────────────────────────────────────────────────────────┐
│ A 顶部通栏 32px（深色）                                        │
│   客服电话/平台slogan ............ 语言 手机版 帮助 登录/注册   │
├──────────────────────────────────────────────────────────────┤
│ B 粘性头部 64-72px（白底）                                     │
│   Logo+平台名 │ 搜索框 500-600px(分类下拉+输入+主色按钮)        │
│                │ 询价单(角标) 购物车 消息                        │
│   搜索框下：热搜词 4-6 个                                       │
├──────────────────────────────────────────────────────────────┤
│ C 主导航 44-48px（主色底）                                     │
│   [全部分类▼深色块] 首页 找货源 行情中心 求购大厅 供应商         │

│   │分类导航 │ │ 轮播：主色渐变+卖点+CTA    │ │ 2×2 图标卡片     │  │
│   │8-12项  │ │ 指示点/箭头               │ │                 │  │
│   └────────┘ └──────────────────────────┘ └────────────────┘  │
├──────────────────────────────────────────────────────────────┤
│ E 行情滚动条（卡片，左侧橙色"行情快报"色块，无缝循环滚动）       │
├──────────────────────────────────────────────────────────────┤
│ F 采购/供应专区（Tab 切换，4 列信息条：品类+规格+数量+地+时间）  │
├──────────────────────────────────────────────────────────────┤
│ G 热卖现货（标题栏"竖条+H2+查看全部"，5列产品卡，8-15条）        │
├──────────────────────────────────────────────────────────────┤
│ H 认证供应商（4 列供应商卡）                                    │
├──────────────────────────────────────────────────────────────┤
│ I 价格走势（白色卡：标题+周期切换 月/季/年，Chart.js 256px高）   │
├──────────────────────────────────────────────────────────────┤
│ J 平台服务（5 列图标：直供/物流/保障/金融/客服）                │
├──────────────────────────────────────────────────────────────┤
│ K 行业资讯（3 列：分类标签+标题+来源日期）                      │
├──────────────────────────────────────────────────────────────┤

```

### 1.2 区块规格

| 区块 | 内容要点 | 数据来源 |
|------|----------|----------|
| A 通栏 | 电话可虚构 400；登录/注册用文字链 | 静态 |
| B 头部 | 搜索框边框 2px 主色；按钮文字随行业（搜钢/搜货/搜索） | 热搜静态数组 |
| C 导航 | "全部分类"块比其他项深一阶；展开面板 5 列 | 类目数组 |
| D Hero | Banner 3-5 张，渐变底不用外部图；右侧入口：发布采购/免费开店/我要报价/阳光采购 | Banner 数组 |
| E 行情条 | 每项：品名(灰) + 价格(黑粗) + 涨跌(带箭头)；30ms/帧位移 | ticker 数组 |
| F 专区 | 两条 Tab；每条信息含数量与城市；时间用橙色 | 专区数组 |
| G 产品 | 5 列（lg）/3（md）/2（sm） | products 数组 |
| H 供应商 | 4 列（lg）/2（md）/1 | suppliers 数组 |
| I 走势 | 折线面积图，主色 0.15 透明填充；双序列（期/现）可选 | chart 数组 |
| J 服务 | 图标用 FontAwesome，文字 ≤4 字 | 静态 |
| K 资讯 | 3 条，标签：行情分析/政策/报告 | 静态或数组 |
| L 页脚 | 必含 ICP 备案虚构号、版权年份 | 静态 |

### 1.3 行业变体

- **steel/mineral/nonferrous/chemical/energy/agriculture（行情导向）**：全量保留 E、I；I 图表标题用该行业主力品种。
- **industrial（MRO）**：删 E 或改"公告条"；I 替换为"品牌专场"（品牌 Logo 横排卡片）+ "企业客户案例"；G 卡片显示 MOQ 与协议价标。
- **fruit/seafood/frozen/livestock（生鲜导向）**：D 区 Banner 文案主打产地/冷链/检疫；F 专区突出产地城市；I 走势图可保留但品种改为产季品种（如砂糖橘），或替换为产地地图卡片。

### 1.4 移动端折叠顺序

1. A 区只留"登录/注册"。
2. B 区 Logo 与角标同行，搜索框独占第二行全宽。
3. C 区"全部分类"变汉堡，类目项横滑。
4. D 区顺序：Banner → 快捷入口（横排 4 个）→ 分类入口收起。
5. E 行情条保留（文字缩小到 12px）。
6. G 网格 2 列；H 1 列；K 1 列。

## §2 产品列表页

### 2.1 线框

```
┌──────────────────────────────────────────────────────────────┐
│ A/B/C 同首页（头部三件套，可省略 Hero）                        │
├──────────────────────────────────────────────────────────────┤
│ 面包屑：首页 > 板材 > 热轧板卷                                  │
├──────────────────────────────────────────────────────────────┤
│ 筛选区（白色卡，每行一个筛选维度，横向排列标签）                 │
│  品类：[全部][热轧][冷轧][镀锌]…                               │
│  品牌/钢厂：[全部][沙钢][首钢][宝武]（多选，选中主色描边）       │
│  【行业指标】如 规格/牌号/品位：区间输入或标签                  │
│  价格：[最低] - [最高]（元/吨）        仓库地：[城市下拉]        │
│  [清空全部]                                       [确定筛选]    │
├──────────────────────────────────────────────────────────────┤
│ 排序工具栏：综合 | 价格↑↓ | 最新发布 | 成交量    右：视图切换   │
│ 共 128 件商品                                   [栅格][列表]    │
├──────────────────────────────────────────────────────────────┤
│ 产品网格 4 列 × 3 行（数据驱动，12-24 条）                     │
├──────────────────────────────────────────────────────────────┤
│ 分页：上一页 1 2 3 4 5 … 32 下一页 │ 每页 [24▼] 条             │
├──────────────────────────────────────────────────────────────┤
│ L 页脚                                                         │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 规格要点

- 筛选维度 **3-6 个**，必须含行业画像中的核心指标（如矿石必有品位、化工必有牌号）。
- 已选筛选条件以可关闭的 chip 形式回显在筛选区顶部。
- 原型交互要求：标签可选中变色；价格区间输入；"确定筛选"后重新过滤 JS 数组并刷新网格（真过滤，不是假按钮）。
- 排序至少实现"价格升/降"与"默认"两种真实排序。
- 列表视图（可选）：横向卡片，左图右文，信息密度更高，适合工业品参数对比。
- 空结果态：显示"无符合条件商品 + 清空筛选按钮 + 发布求购 CTA"。

### 2.3 响应式

- md 以下筛选器折叠为底部"筛选"按钮，点击全宽抽屉。
- 网格 4→2 列；分页省略中间页码，保留前后页与当前页。

## §3 产品详情页

### 3.1 线框

```
┌──────────────────────────────────────────────────────────────┐
│ 面包屑：首页 > 板材 > 热轧板卷 > 当前商品                      │
├──────────────────────────────────────────────────────────────┤
│ 主信息区（白色卡，两栏）                                       │
│ ┌────────────────────┐ ┌──────────────────────────────────┐  │
│ │ 左 5/12            │ │ 右 7/12                          │  │
│ │ 主图占位 480×480    │ │ 标题（含完整牌号规格）             │  │
│ │ 缩略图 4 张横排     │ │ 价格区：¥3,820/吨（大号橙色）       │  │
│ │                    │ │ [行业指标标签行：理计/现货/含税]     │  │
│ │                    │ │ 规格选择：可选规格块（选中主色描边）  │  │
│ │                    │ │ 数量：[- 100 +] 吨（批量步进值）     │  │
│ │                    │ │ 交货地：[城市下拉] 仓库：上海宝山库   │  │
│ │                    │ │ [立即询价] [加入询盘] [收藏]         │  │
│ └────────────────────┘ └──────────────────────────────────┘  │
├──────────────────────────────────────────────────────────────┤
│ 供应商信息条（白色卡）：Logo+公司名+认证标+主营+成交+[进店]     │
├──────────────────────────────────────────────────────────────┤
│ 详情 Tabs：产品详情 | 规格参数 | 交易须知 | 评价(126) | 资质    │
│  ─ 产品详情：图文段落（用占位图块）                             │
│  ─ 规格参数：两列表格（牌号/规格/产地/交货地… 用行业字段）       │
│  ─ 交易须知：计价方式/付款方式/运输/发票/退换                  │
│  ─ 评价：2-3 条评价卡（公司名脱敏+评分+文字）                   │
│  ─ 资质：证书占位网格（ISO/经营许可/验厂报告）                  │
├──────────────────────────────────────────────────────────────┤
│ 相关推荐：同品类产品 4-5 列                                    │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 规格要点

- 价格是页面视觉重心：24-28px、橙色、粗体；价格后标注计价口径（含税 / 理计 / 自提）。
- 数量步进值符合行业：钢材以吨步进（默认 30-35，约一整车），工业品按 MOQ 步进。
- 主 CTA"立即询价"，次 CTA"加入询盘"；B2B 场景不出现"立即购买/秒杀"。
- Tabs 必须真实切换；规格参数表字段从行业画像取（≥6 行）。
- 信任组件三连：供应商认证标、交易保障图标行、资质证书。

### 3.3 响应式

- 主信息区两栏变一栏：图在上、信息在下；缩略图可横滑。
- 底部移动端固定操作条：[客服][收藏] + [加入询盘][立即询价]。

## §4 RFQ 询价页

### 4.1 线框

```
┌──────────────────────────────────────────────────────────────┐
│ 页头标题：发布采购询价                            我的询价单>   │
├──────────────────────────────────────────────────────────────┤
│ 表单（白色卡，label 右对齐 120px，表单项纵向 24px 间距）        │
│ ① 采购品类*：[关联品类下拉]  品名/牌号*：[___________]          │
│ ② 规格要求*：[多行文本，如 Φ20×9m，HRB400E，理计]              │
│ ③ 采购数量*：[___] [单位▼ 吨/kg/件]                            │
│ ④ 目标价：[___] 元/单位（选填，可勾选"面议"）                   │
│ ⑤ 交货地*：[省][市] 仓库/工地详细地址：[______]                 │
│ ⑥ 期望交货期*：[日期选择]   包装要求：[______]                  │
│ ⑦ 付款方式：[货到付款/月结/电汇/承兑 下拉] 发票：[专票▼]         │
│ ⑧ 附件：[上传占位]（规格书/图纸，jpg/pdf，≤10MB）              │
│ ⑨ 供应商可见范围：○全部供应商 ○指定供应商（多选弹窗）           │
│ ⑩ 备注：[多行文本]                                             │
│ [暂存草稿]                       [同意《询价发布规则》□][发布]  │
├──────────────────────────────────────────────────────────────┤
│ 右侧（可选侧栏）：询价流程说明 4 步 + 历史询价 3 条             │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 规格要点

- 必填字段 7 个（标 *），字段随行业微调：钢材问计重方式，冻品问温控，工业品问品牌型号与 MOQ。
- 原型校验：必填为空时点发布，对应字段红色描边 + 下方错误文案，顶部汇总提示。
- 发布成功后：toast 成功 → 跳转"询价单详情态"（可用页内状态切换模拟：状态"报价中 3/6 家已报价" + 报价列表 2-3 条）。
- 附件区为虚线框拖拽占位，点击只做样式反馈，不接真实上传。
- 表单上方可放进度提示（① 填需求 → ② 选供应商 → ③ 发布成功）。

### 4.3 响应式

- label 改为顶部对齐；单栏；提交按钮固定底部全宽主按钮。

```
┌──────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────┤
```

- 移动端店招压缩高度，数据条 2×2 宫格，侧栏类目移到 Tabs 下方横滑。

## 页面间导航关系（原型跳转要求）

```
首页 ──搜索/分类/卡片──> 列表页 ──卡片──> 详情页 ──立即询价──> RFQ
首页 ──发布采购/求购────> RFQ
首页 ──供应商卡/进店───> 店铺页 ──产品──> 详情页
RFQ ──发布成功────────> 询价状态页（页内模拟）
```

原型中这些跳转可用真实 `<a href>` 指向同目录其他页面；仅交付单页时用页内区块切换 / toast 模拟，并在代码注释标明。
