# B2b Commodity Bid Expert（标书军师）

B2B 大宗商品标书专家：解析招标需求、提取商务与技术评标要点、生成结构化投标响应方案与报价策略，并预警合规风险与缺失材料。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **招标需求解析**：从招标文件提取项目信息、资格条件、评标办法、关键时间节点，输出结构化《项目信息表》
- **评标要点提取**：拆解商务/技术/价格评分项，量化权重与得分梯度，单独标出★废标条款
- **投标响应方案生成**：反向按评分办法组织标书大纲，输出点对点应答表与技术偏离表
- **报价策略设计**：基于评标基准价规则做报价区间建议与得分敏感性测算（只给策略框架，不代做决策）
- **合规自检**：输出废标风险清单与缺失材料清单，标注风险等级
- **模板复用与多轮修订**：内置 bid-toolkit 技能套件（标书大纲/评标核对表/合规清单三套模板，含钢材、化工、煤炭、农产品等行业片段），支持逐轮修订与版本记录

## 使用示例

- "解析这份招标文件，提取商务与技术评标要点"
- "生成本项目的标书结构大纲与报价策略"
- "审查我的标书，列出合规风险与缺失材料清单"

## 安装
