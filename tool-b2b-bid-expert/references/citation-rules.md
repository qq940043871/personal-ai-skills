# 引用与定位规范

标书类交付物的全部价值，取决于"每句话能不能被指着原文核对"。
本文件规定引用的写法，`audit_bid_package.py` 会按此校验。

## 1. 页码口径

- **一律用物理页序**（`tender_ingest.py` 输出的 `[[P12]]` 编号），写作 `P12`。
- 不猜印刷页码。招标文件常有扉页、目录、附件导致"印刷页码 = 物理页码 − N"，
  猜错一次，整份应答表的引用全部失效。
- 用户明确告知偏移量时（如"正文第 1 页是 PDF 第 7 页"），可换算为印刷页码并标注
  `P13（正文第7页）`。
- DOCX 无可靠分页：引用写成 `第X章 + 段落原文前 12 字`，例如
  `第三章「评标办法」段「本项目采用综合评分法」`。不要编造页码。

## 2. 三种引用状态，不许留空

| 状态 | 写法 | 使用条件 |
|---|---|---|
| 已定位 | `P12` | 已在 `tender.md` 对应页找到原文 |
| 待核对 | `待核对（推测在第三章）` | 有线索但未确认，**必须给出推测依据** |
| 无此条款 | `招标文件未约定` | 逐页确认确实没有，不能因为"没找到"就写这句 |

禁止：`见招标文件`、`详见相关条款`、`按招标文件要求` —— 这类写法等于没引用，
质检脚本会判为缺失。

## 3. ★ / ▲ 条款的响应要求

- **★ 条款**（实质性要求）：必须写"实现方式或具体参数值"，不能只写"满足"。
  - ✗ `满足`
  - ✓ `按 PT.A 级供货，公差实测值随货提供，检测报告编号见附件 4`
- **▲ 条款**（重要参数）：可写"满足 + 支撑证据"，无支撑的会被判低档。
- 每条 ★ 条款都必须进《技术偏离表》，即使无偏离也要写"无偏离"并注明依据。

## 4. 偏离表写法

| 偏离类型 | 判定 | 处理 |
|---|---|---|
| 正偏离 | 我方优于要求（如交期 12 天 vs 要求 15 天） | 写明优在哪，可争取加分 |
| 无偏离 | 完全一致 | 写"无偏离"+ 页码 |
| 负偏离 | 我方劣于要求 | **★ 条款负偏离 = 废标**，必须提前告知用户并给替代方案 |

负偏离不许隐瞒、不许用"基本满足""可接受"含糊过去。这类词会被质检脚本和评标专家同时抓。

## 5. 严禁编造（硬红线）

以下内容**只能由用户提供真实材料**，禁止生成具体值：

- 资质证书编号、认证机构、有效期
- 业绩项目名称、合同金额、业主单位
- 检测报告编号、检测数据
- 项目经理姓名、证书编号

允许生成的：这些材料的**清单、用途、常见出具方、准备周期**。
写法示例：`ISO9001 证书（需用户提供扫描件，附件 2 位）`。

质检脚本 E4 会抓"我司具备…资质"但同段无"附件/详见/编号"支撑的句子。

## 6. 报价类输出的边界

- 只给**测算与策略**：报价区间、得分敏感性、拆分建议。
- 不给"建议报价 X 元"这种最终数字——最终决策权在用户，且成本数据只有用户有。
- 所有测算必须写明假设（成本构成、竞争对手数量、基准价规则）。

## 7. 交付前必跑

```bash
# 1) 摄入招标文件（拿到 [[P12]] 锚点）
python scripts/tender_ingest.py 招标文件.pdf --out ./_tender

# 2) 生成应答表/偏离表/废标清单后，质检
python scripts/audit_bid_package.py ./out --tender ./_tender
```

`audit_bid_package.py` 退出码 0 才能交付。它检查：占位符残留、表格行缺页码、
空表、无支撑的资质声称、★条款页码覆盖、★条款空泛响应。
