# 农产品 标书行业片段

> 用法：并入通用骨架。农产品投标的核心是"食品安全资质链"与"产地/季节供应能力"。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 20–30 | 供货业绩、应急保供能力权重高 |
| 技术分 | 25–40 | 质量标准、检测、冷链、溯源 |
| 价格分 | 35–50 | 常按"下浮率"报价（对标市场指导价） |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 营业执照 + 食品经营许可证 | 市场监管 | 许可经营项目与投标品类不符 |
| 食用农产品合格证 / 产地证明 | 产地农业部门/合作社 | 外省产地证明格式不被认可 |
| 检验检疫合格证明 | 海关（进口）/ 农业部门 | 进口品类必需，常漏 |
| 第三方检测报告（农残/重金属/真菌毒素） | CMA/CNAS | 检测项未覆盖招标要求的全部农残指标 |
| 冷链资质与车辆温控记录 | 自备 | 只写"有冷藏车"，无温控记录样例 |
| 保供方案（应急调运） | 自备 | 无具体产地/库存/调运时限，技术分低档 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **质量标准与等级**：一等品/二等品、规格（如苹果 80mm 以上）必须逐项响应。
2. **农残限量标准**：GB 2763 的具体项目与限量值，笼统写"符合国标"常被判负偏离。
3. **供货周期与季节性**：反季节供应须写清产地与调运方案。
4. **包装与标识**：净重、产地、生产日期、保质期、储存条件，标签不合规是高频扣分。
5. **溯源要求**：一物一码 / 批次可追溯，常为▲评分项。

## 4. 加分项抓手

- 自有基地 / 合作社直采协议（成本与稳定性双背书）
- 冷链仓储（冷库容积、温区、备案）
- 大型团餐/商超/学校供应业绩（这类客户认可度最高）
- 食品安全管理体系（ISO22000/HACCP）
- 应急保供承诺（极端天气、疫情场景演练记录）

## 5. 报价注意

- 报价方式常为"下浮率"或"对标当地批发市场均价"，算法不同最优策略完全不同。
- 损耗率（叶菜 10–15%）必须计入成本。
- 冷链运输与退换货成本别漏算。

## 6. 本行业高频废标原因

【致命】食品经营许可范围不含投标品类
【致命】检测项目未覆盖招标要求的全部指标
【致命】★规格/等级负偏离
【高风险】冷链仅口头承诺、无温控记录
【高风险】产地证明缺失或格式不符
