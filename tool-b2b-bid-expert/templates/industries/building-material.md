# 建材（水泥/砂石/混凝土/钢材制品）标书行业片段

> 用法：并入通用骨架。建材项目的分水岭是"本地化供应能力"和"检测频次承诺"。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 15–25 | 本地业绩、搅拌站/仓储距离加分 |
| 技术分 | 25–40 | 配合比、强度等级、耐久性指标 |
| 价格分 | 40–55 | 价格权重高，运距直接影响成本 |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 营业执照 + 生产资质（水泥生产许可证） | 工商/市场监管 | 经销商须附生产商授权 |
| 产品认证（如水泥 GB 175 符合性） | 认证机构 | 认证覆盖品种不全 |
| 第三方检测报告（强度/安定性/凝结时间） | CMA | 报告超 6 个月常被质疑 |
| 环保合规（排污许可证） | 生态环境部门 | 砂石料场无排污许可被否决增多 |
| 运输与卸货方案 | 自备 | 未写清卸货责任与等待费 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **强度等级与龄期**：42.5 / 52.5、28 天强度承诺须与检测报告一致。
2. **执行标准年份号**：GB 175、GB/T 14684（砂）、GB/T 14685（石）版本写错即负偏离。
3. **供货半径与到场时间**：★常要求"2 小时内到场"，须用搅拌站/中转库位置证明。
4. **检测频次**：每批次随车提供出厂合格证与检测报告，是常见▲项。
5. **冬期/雨期施工措施**：北方项目常设专项评分。

## 4. 加分项抓手

- 本地搅拌站 / 中转库（附租赁合同与位置图）
- 自有运输车队（罐车数量、GPS 调度）
- 绿色建材认证、低碳水泥（政府采购加分明显）
- 与大型项目合作业绩（地铁、桥梁、市政）

## 5. 报价注意

- 运距按实际路线而非直线距离，超运距另计要写进报价说明。
- 泵送费、等待费、夜间施工加成是否含在单价内。
- 水泥价格季节性波动大，长单须约定调价窗口。

## 6. 本行业高频废标原因

【致命】生产许可/授权链缺失
【致命】★到场时间承诺无支撑证据
【致命】检测报告品种或强度等级不符
【高风险】环保排污许可缺失（砂石类）
【高风险】卸货责任与费用未响应
