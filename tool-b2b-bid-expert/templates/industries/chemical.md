# 化工原料 标书行业片段

> 用法：并入通用骨架。化工品投标的第一杀手是"危化品资质"，第二是"技术参数逐项响应"。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 15–25 | 危化品经营资质、运输资质权重高 |
| 技术分 | 35–50 | 纯度/杂质谱/包装/储存条件是主战场 |
| 价格分 | 30–45 | 部分项目采用"综合性价比"而非纯低价 |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 危险化学品经营许可证 | 应急管理部门 | 许可范围不含投标品种即废标 |
| 安全生产许可证（生产商） | 应急管理部门 | 贸易商须提供上游生产商证件 |
| 危化品道路运输资质 / 押运员证 | 交通部门 | 委托运输须附委托协议与承运方资质 |
| MSDS（安全技术说明书）+ 中文标签 | 生产商 | 版本过期、成分与实际不符 |
| 第三方检测报告（纯度/杂质） | CMA/CNAS | 检测项目与招标技术指标不一一对应 |
| 包装物证明（危包证） | 海关/检测机构 | 出口项目必需，国内项目常被忽略 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **纯度与杂质谱**：只写"≥99.5%"不够，杂质单项上限（如重金属、水分、色度）常是★条款。
2. **执行标准**：GB / HG / 企业标准 的差异，企业标准须附备案证明。
3. **包装规格**：200L 桶 / IBC 吨桶 / 槽车 / 25kg 袋，包装不符即负偏离。
4. **储存与保质期**：保质期承诺、避光防潮条件、超期处理方案。
5. **应急响应**：泄漏处置预案、应急联系人 24h 电话，常为▲评分项。

## 4. 加分项抓手

- 生产商直供 + 产能证明（贸易商劣势明显）
- 自有化验室 / 批次留样制度
- 危化品专用仓储（有消防验收与环评）
- 危化品运输自有车队（含 GPS 监控与押运员配置）
- 绿色化学品 / REACH 注册（出口或外资客户项目）

## 5. 报价注意

- 价格是否含包装物回收（吨桶押金）——漏算即亏损。
- 运费按危化品运输计价，普通货运报价会低报后亏。
- 汇率与原料波动条款（长单必谈）。

## 6. 本行业高频废标原因

【致命】危化品经营许可范围不含投标品种
【致命】MSDS 缺失或成分与检测报告冲突
【致命】包装规格与技术规格书不符
【高风险】未提供危化品运输资质或委托协议
【高风险】杂质指标只给总量不给单项
