# 煤炭 标书行业片段

> 用法：生成标书大纲与评分核对表时，把本片段并入通用骨架。
> 煤炭采购的废标点集中在"资质证照"和"质量指标承诺"两处。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 15–25 | 矿方直供/一手货源加分明显 |
| 技术分 | 25–40 | 煤质指标（热值/硫分/灰分/水分）+ 储运方案 |
| 价格分 | 40–55 | 价格权重普遍偏高，且常按"到厂标煤单价"折算 |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 营业执照（含煤炭经营/销售） | 工商 | 2019 年后取消煤炭经营资格证，但仍常被要求提供旧证 |
| 煤矿安全生产许可证（矿方直供时） | 应急管理部门 | 贸易商投标时易被要求提供上游矿方证件 |
| 煤质检验报告（第三方 CMA） | 检测机构 | 报告批次与投标批次不对应 |
| 运输资质 / 道路运输经营许可证 | 交通部门 | 自运或委托运输的责任划分未写清 |
| 近三年同类业绩 | 自备 | 电厂/钢厂/水泥厂客户业绩含金量不同，看招标文件是否限定 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **煤质指标承诺**：收到基低位发热量（Qnet,ar）、全硫（St,d）、灰分（Ad）、全水（Mt）四项必须逐项响应，缺一项即负偏离。
2. **指标口径**：收到基 / 空气干燥基 / 干燥基 混用是重灾区，照抄招标文件口径。
3. **计量与化验**：以谁的化验为准（到厂化验/第三方/仲裁样）必须明确，否则结算必吵。
4. **供货连续性**：★常要求"月度均衡供货"，承诺总量不承诺月度节奏 = 负偏离。
5. **环保要求**：低硫低灰指标、防尘覆盖、绿色运输（国五/国六车）常为▲条款。

## 4. 加分项抓手

- 矿方直供证明 / 长协合同（价格稳定性背书）
- 自有洗选能力（可稳定控制硫分灰分）
- 储煤场地（封闭煤棚）面积与环评批复
- 铁路/港口运力保障（尤其跨省长距离供应）

## 5. 报价注意

- 报价口径统一到"元/吨·到厂"或"元/大卡"，混用会导致评标无法比较。
- 热值奖惩条款（低于承诺热值如何扣款）必须算进成本。
- 运费波动、铁路计划费、港杂费是否含在单价内。

## 6. 本行业高频废标原因

【致命】煤质指标漏项或只承诺"符合国标"不给具体数值
【致命】未提供运输资质或运输责任划分
【致命】化验口径与招标文件不一致（基态混用）
【高风险】月度供货能力无量化承诺
【高风险】环保运输要求（车辆排放标准）未响应
