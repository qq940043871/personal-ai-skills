# 物流运输 标书行业片段

> 用法：并入通用骨架。物流标的关键词是"运力证明"和"时效承诺的可验证性"。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 20–30 | 自有车辆数、保险、事故率 |
| 技术分 | 30–40 | 线路方案、时效保障、信息化 |
| 价格分 | 35–50 | 按吨公里或单车次报价 |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 道路运输经营许可证 | 交通部门 | 普通货运 / 危险品 / 大件 类别须匹配 |
| 车辆行驶证 + 营运证 | 自备 | 挂靠车辆须附挂靠协议 |
| 驾驶员从业资格证 | 交通部门 | 危货押运员证常漏 |
| 货物运输险保单 | 保险公司 | 保额低于货值被判不响应 |
| 近三年同类线路业绩 | 自备 | 无回单/签收单佐证 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **时效承诺**：★常写"X 小时送达"，须配线路图、里程、限速与装卸时间测算，空口承诺必被判负偏离。
2. **车辆标准**：车型（厢式/平板/冷藏）、载重、尾板、GPS 全覆盖。
3. **信息化对接**：要求对接甲方 TMS/WMS、提供在途可视化，常为▲项。
4. **异常处理**：货损、延误、交通事故的响应机制与赔付标准。
5. **回单管理**：纸质/电子回单的回收时限与归档方式。

## 4. 加分项抓手

- 自有车队规模（附车辆清单：车牌、车型、载重、购置年限）
- 仓储+运输一体化能力（中转库、分拨中心）
- GPS/北斗在途监控系统截图
- 大型货主长期合作业绩（快消、汽车、家电）
- 绿色运输（新能源车辆比例）

## 5. 报价注意

- 报价口径：吨公里 / 单车次 / 包月，混报无法比价。
- 空驶费、等待费、装卸费、过路费是否含在报价内。
- 油价联动条款（长单必谈）。

## 6. 本行业高频废标原因

【致命】运输许可类别与投标货物不符（普货投危货）
【致命】★时效承诺无测算依据
【致命】保险保额低于货值
【高风险】挂靠车辆无协议
【高风险】未响应信息化对接要求
