# 工业品备件 / MRO 标书行业片段

> 用法：并入通用骨架。MRO 招标的特点是"品类多、金额碎、交期严"，拼的是目录管理与库存响应。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 20–30 | 供货范围覆盖率、历史履约评价权重高 |
| 技术分 | 25–35 | 品牌/替代型号的等效性论证是关键 |
| 价格分 | 35–50 | 常按"清单综合折扣率"评标 |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 营业执照（经营范围覆盖机械/电气/五金） | 工商 | 品类跨度大时范围不全 |
| 品牌授权 / 一级代理证明 | 品牌方 | 授权书过期或限定区域 |
| 质量管理体系认证 | 认证机构 | — |
| 常用件库存证明（仓库照片/库存清单） | 自备 | 无库存证明，交期承诺不可信 |
| 近三年同类框架协议业绩 | 自备 | 单次采购业绩不如框架协议有说服力 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **型号等效性**：允许替代时必须提交《等效性说明》（参数逐项对照表），只写"可替代"必被判负偏离。
2. **交期承诺**：★常要求"常用件 24h、非常用件 7 天"，须按品类分别承诺。
3. **原厂件 vs 副厂件**：招标文件常明确"必须原厂"，副厂报价直接废标。
4. **质保期与响应时效**：质保 12/24 个月、4 小时响应/48 小时到场，逐项对齐。
5. **清单完整性**：几百上千行的清单，漏报一行可能被判"未实质响应"。

## 4. 加分项抓手

- 本地仓 + 常用件安全库存（附 SKU 清单与库存量）
- 与品牌方的年度框架协议
- 备件管理系统 / 一物一码（可查库存与在途）
- 驻厂服务工程师（响应时效的核心证据）

## 5. 报价注意

- 清单报价注意"单位"陷阱：件/套/台/米，单位错价格差十倍。
- 综合折扣率报价时，先确认基准价来源（招标人清单价 / 市场价 / 上期中标价）。
- 小额多批次配送成本别漏算。

## 6. 本行业高频废标原因

【致命】清单漏项 / 单位错误
【致命】应原厂件却报副厂
【致命】★交期承诺未按品类分档
【高风险】替代型号无等效性说明
【高风险】授权书过期或区域不符
