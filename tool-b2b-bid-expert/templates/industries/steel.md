# 钢材 / 金属材料 标书行业片段

> 用法：生成标书大纲与评分核对表时，把本片段并入通用骨架，替换对应章节。
> 标注【】的是本行业高频废标点，必须在应答表里逐条落到页码。

## 1. 评标权重典型分布

| 评分块 | 常见区间 | 本行业特点 |
|---|---|---|
| 商务分 | 15–25 | 业绩权重高，且常限定"同类品种+同类下游行业" |
| 技术分 | 30–45 | 材质标准、公差、表面质量、检测能力是主战场 |
| 价格分 | 35–45 | 多用评标基准价法，低价不一定高分（防恶意低价） |

## 2. 必答资格件（缺一件即废标）

| 材料 | 常见出具方 | 易错点 |
|---|---|---|
| 营业执照（经营范围含金属材料/钢材贸易） | 工商 | 经营范围不含"钢材"被否决的案例极多 |
| 生产厂家授权书 / 代理证明 | 钢厂 | 代理商常漏；授权期限须覆盖合同履约期 |
| ISO9001（部分要求 ISO14001/45001） | 认证机构 | 证书过期、认可范围不含钢材 |
| 近三年同类业绩（合同+发票+验收单） | 自备 | 只给合同不给发票，常被判不实质响应 |
| 第三方检测报告（CMA/CNAS） | 检测机构 | 报告型号与投标牌号不一致 |
| 供货能力证明（产能/排产计划） | 钢厂 | 只写"产能充足"无数据，技术分直接低档 |

## 3. 技术偏离高发区（★/▲ 高频落点）

1. **执行标准版本**：GB/T 700、GB/T 709、GB/T 3274 的年份号写错即负偏离。
2. **厚度/宽度公差等级**：PT.A / PT.B 混淆是最常见的技术性废标。
3. **交货期与批次**：★交货期常与违约金绑定，承诺 15 日却写"视排产情况"= 负偏离。
4. **计量方式**：地磅称重、理论计量、抄码计重的差异会引发结算争议，须照抄原文口径。
5. **质保书/炉批号追溯**：要求"随货提供质保书并可按炉批号追溯"时，须写清追溯机制。

## 4. 加分项抓手（可提前 1–2 周准备）

- 自有实验室 / CNAS 认可（技术分档位提升明显）
- 钢厂一级代理资质、年度框架协议
- 区域仓储能力（前置库、加工配送中心）——"供货保障"章节的核心证据
- 加工配套（开平、纵剪、折弯）能力，写清设备清单与产能

## 5. 报价注意

- 价格分公式先算一遍：基准价是"最低价"还是"平均价下浮"，两种算法最优报价完全不同。
- 钢材价格随行就市，若合同期长，须在商务条款里约定调价机制（否则中标即亏损）。
- 运费、吊装、取样送检费用是否含在单价内，逐项确认。

## 6. 本行业高频废标原因

【致命】经营范围不含钢材贸易
【致命】★公差等级负偏离且未在偏离表声明
【致命】业绩只提供合同、无发票或验收证明
【高风险】授权书期限短于合同期
【高风险】检测报告牌号/规格与投标产品不符
