# 子代理并行写章

章数 > 8 时手工写笔记会拖很久。本文件是可以直接抄的提示词模板与核验方法。

## 并发上限

**本机 3 并发可用**。曾 4 并发被风控拒（429）。

## 必须写清的五件事

缺任何一条，子代理产出的笔记就不合契约：

1. **输入是已抽好的** `pages_text/chNN.txt`（或 `pages_ocr/chNN.txt`）——让它们直接读，
   别各自去抽一遍（浪费 token 还会抽不一致）
2. **必须先完整读取 `references/notes-format.md`**，严格按契约写
3. **输出绝对路径**（`$NOTES_DIR/chNN.md`），目录不存在要先创建
4. **该章预期的分节清单**（对应原书 L2/L3 小节名），避免它们自造节标题
5. **不要写 `- **误区**：` 前缀**（模板已有 ⚠ 图标），但 `- **深入**：` 要保留

非技术书额外说明：第 2 个固定小节叫 `## 关键论断`，不是「代码要点」。

## 提示词模板

```
你要为一本学习站写第 {ch} 章的笔记。

输入（已抽好，直接读，不要自己去抽 PDF）：
  {NOTES_DIR}/../pages_text/{ch}.txt
  如果该文件不存在，改读 {NOTES_DIR}/../pages_ocr/{ch}.txt
  OCR 文本含形近符号错误（$ 被读成 S、0/O、1/l 混淆），按技术常识还原，不要把错别字写进笔记。

动手前必须先完整读一遍契约文件：
  {SKILL_DIR}/references/notes-format.md
严格按它的结构写，不要自创层级。

本章预期分节清单（对应原书小节名，直接用作 ## 标题）：
{列出该章的小节名}

额外要求：
- 输出到绝对路径 {NOTES_DIR}/{ch}.md，目录不存在先创建
- 不要写 "- **误区**：" 前缀（模板已有 ⚠ 图标），但 "- **深入**：" 要保留
- 每个代码块第一行必须有 "// caption: 说明"
- 自测题 3-6 道，**Q 与 A 必须成对且分行写**
- 忠于原书，具体到类名/方法名/参数/数字，不编造原书没有的结论

完成后回报：文件绝对路径 + 字节数 + 本章卡片数/代码块数/自测题数。
```

## 派发节奏

- 一条消息里并发 3 个 `general-purpose` 子代理
- 每批完成后核验产物，再派下一批
- 每个子代理认领 2-4 章

## ⚠ 子代理可能只回 agent ID 而不落盘

**必须用 `os.listdir` 核验真实产物**，不能只信它自报成功。
历史上多次发生：子代理回报"已完成"，实际文件根本没写。

```python
import os
notes = r"...\notes"
for cid in ["ch01", "ch02", "ch03"]:
    p = os.path.join(notes, cid + ".md")
    print(cid, os.path.getsize(p) if os.path.isfile(p) else "MISSING")
```

缺文件就重派，重派时提示词里明确加一句：
> 这次是重派，上一次没有真实写出文件。务必用 Write 工具真实落盘，并在回复里给出文件字节数。

## ⚠ 子代理自报"结构校验通过"不可信

即使子代理说它检查过了，也**必须自己跑**：

```bash
$PY scripts/audit_notes.py --book $BOOK_DIR --profile tech
```

实测：18 章里子代理都自报通过，实际查出 3 章共 21 个代码块缺 caption。
审计脚本第一版还因为没排除代码块内的 `#` 注释而报出 `H1=51` 的假警报——
现在 `audit_notes.py` 已内置正确处理，但你若自己写审计脚本，务必先按 ``` 切块。
