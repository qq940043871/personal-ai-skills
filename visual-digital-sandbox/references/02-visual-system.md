# 视觉系统

沙盘的视觉目标不是"炫"，而是**像一台摆在暗房里的实体模型**：一块有厚度的地悬在深色空间里，
主体靠光塑形，界面安静地围在四角。

## 一、色彩管线（最容易全盘搞错的一环）

three r149 没有默认开启色彩管理。`new THREE.Color(0x2a3a48)` 得到的 0.16/0.23/0.28
会被当作**线性反射率**直接进光照计算，输出到 sRGB 屏幕变亮成 `#8a97a3` 的浅灰。

骨架里统一用 `C(hex)` 包一层：

```js
function C(hex){
  if (hex === undefined || hex === null) return new S.THREE.Color(0xffffff);
  if (hex.isColor) return hex.clone();
  return new S.THREE.Color(hex).convertSRGBToLinear();
}
```

**规则**：凡是 `color:` / `emissive:` / `fog` 里的十六进制颜色，一律写成 `C(0x…)`。
CanvasTexture 要设 `texture.encoding = THREE.sRGBEncoding`（`canvasTex()` 已经处理）。

转换之后，颜色会**明显变深**，这是对的——接着按第 2 节重新配光。

## 二、曝光三件套：albedo / 光照 / exposure

线性管线下，漫反射近似 `albedo / π × 光强 × N·L`。想让画面"正常曝光"：

| 项 | 合理区间 | 说明 |
|---|---|---|
| albedo（材质基色 sRGB） | 0.35 ~ 0.55（`#5a` ~ `#8c`） | 低于 0.2 会塌成剪影，高于 0.7 会整片泛白 |
| 定向光强度 | 1.5 ~ 2.5 | 黄昏模板 1.7 配 `#ffc79a` |
| 半球光 / 环境光 | 0.3 ~ 0.6 / 0.15 ~ 0.3 | 只负责托住暗部，别当主光用 |
| 曝光 | 0.9 ~ 1.1 | ACES 色调映射 |

**踩过的坑**：把"夜色感"寄托在压暗 albedo 上，结果画面变成全黑剪影。
夜色应该来自**背景、雾、曝光**，而不是让所有材质变成黑体。

## 三、三时段调色板

| 时段 | 定向光 | 天光 | 窗光强度 | 用途 |
|---|---|---|---|---|
| `day` | `#fff6e8` × 1.7 | `#bcd8ea` × 0.5 | 0.12 | 汇报、规划评审（明亮、信息密度优先） |
| `dusk` | `#ffc79a` × 1.7 | `#6f93b4` × 0.5 | 0.9 | **默认**。暖阳 + 冷天光，反差最好看 |
| `night` | `#8fa8d8` × 0.55 | `#35506b` × 0.42 | 1.0 | 夜间生产、告警演示（窗光成为主要光源） |

光比经验值：**定向光 : 天光 ≈ 3:1**。两头都高 = 无阴影的塑料感。

| 女儿墙 / 屋顶机组 | `#8695a1` / `#8c9ba7` | 0.8 / 0.6 | — | 顶部细节靠这两件撑住剪影 |

### 窗格密度（白模感的元凶）

```js
var floors = Math.max(2, Math.round(h / 4));   // 一层 ≈ 4 单位
var bays   = Math.max(2, Math.round(w / 2.6)); // 一开间 ≈ 2.6 单位
tex.repeat.set(bays / 8, floors / 22);          // texWindow 本身是 8 列 × 22 行
```

写死 `round(h/9)` 让 54 米高的楼出现 130 行窗，远处必然混叠成均匀亮色——
**"楼像白模"八成不是材质问题，是窗格密度问题**。

## 五、落地感

两套并用，互相兜底：

1. **动态阴影**：定向光 `shadow.radius = 2.4`，`normalBias = 0.12`，太阳高度取台面对角的 1.45 倍
   （角度太低阴影会拖成一地脏斑）。
2. **贴地投影贴片**：径向渐变 CanvasTexture 贴在每栋楼脚下（`addGroundShadow`），
   尺寸取建筑占地 1.5 倍、透明度 0.75。软件渲染或无阴影设备上，就靠它撑住"站在地上"的观感。

## 六、HUD 规范

| 项 | 值 |
|---|---|
| 底色 | `#04080f` → `#050b14` 径向渐变，沙盘浮在其上（`alpha:true` + `scene.background=null`） |
| 面板 | `rgba(10,24,38,.72)` + `backdrop-filter: blur(10px)` + 1px `rgba(96,190,230,.18)` 边框 |
| 四角亮标 | 每个面板左上/右下各一段 11px 直角描边 |
| 主色 | 青 `#35e0ff`；辅色 靛 `#7c8cff`；正常 `#37e0a6`；预警 `#ffb23f`；告警 `#ff5a5f` |
| 字体 | PingFang SC / Microsoft YaHei 栈；数字用 `tabular-nums` 防跳动 |
| 动效 | ≤ 300ms，`cubic-bezier(.22,.61,.36,1)`；禁 bounce / 弹跳 |
| 布局 | 左上标题、左中图层、右侧概览+详情+告警、底部时间轴、左下剖切与机位 |

面板不要铺满——沙盘要靠"留黑"才有模型感。宽度 ≤ 1240px 时自动收起左侧图层与左下工具。

## 七、镜头构图

- `fov` 34~38：窄视角让沙盘更饱满，减少边缘畸变。
- 仰角 26°~32°（`position.y / 水平距离 ≈ 0.5~0.62`）：能同时看到台面布局和台体厚度。
- 沙盘投影宽度应占画面 **70%~80%**；四角略微出画是可以接受的，反而更有沉浸感。
- `target` 略偏向实体密集侧，别把沙盘正中心对准屏幕中心——右侧还有面板。
- 标签在屏幕空间做避让（52×15px 阈值），告警与选中标签永远优先显示。

## 八、性能

- 树用 `InstancedMesh`；楼宇/道路各自独立 mesh，默认模板约 1.6 万三角面、150 draw call。
- 2 万三角面以内、300 draw call 以内属于安全区；再往上优先合并描边线。
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`，高分屏不要放开到 3。
