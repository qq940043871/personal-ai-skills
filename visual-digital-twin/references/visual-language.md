# 视觉语言规范（提炼自抖音 / B站数字孪生爆款案例）

调研来源：短视频平台高赞数字孪生视频（智慧园区/工厂/港口类）与 GhostCat、
CIMPro 等案例库的共性设计要素。做新场景、新面板时必须遵守，避免"程序员审美"。

## 一、爆款五要素（缺一不可）

1. **暗色海洋底**：深蓝黑渐变（#030711 → #0a1c3a），顶部略亮，带网格透视地面
   与缓慢漂移的青/紫光斑。禁纯黑背景。
2. **程序化体块 + 发光描边**：楼宇/设备用几何体块 + 顶盖发光 + 窗户自发光贴图，
   不追求写实建模，追求"霓虹城市感"。
3. **动线三件套**：路网流光（流动光点）、跨域飞线（贝塞尔弧线）、雷达扩散环。
   这三者是"数字孪生感"的核心识别特征。
4. **数据面板玻璃拟态**：半透明深色底 + 1px 青色描边 + 四角亮标 + 标题左侧竖条。
5. **滚动信息流**：底部告警跑马灯常驻，制造"实时运行"氛围。

## 二、设计 Token（与 layout.css 保持一致）

| Token | 值 | 用途 |
|---|---|---|
| --bg-0 / --bg-1 | #030711 / #06101f | 页面底 / 面板底 |
| --cy / --blue / --violet | #22d3ee / #3b82f6 / #a855f7 | 主色三件套 |
| --ok / --warn / --err | #34d399 / #fbbf24 / #fb7185 | 状态语义色 |
| --t1 / --t2 / --t3 | #e6f4ff / #93b8dc / #557ba4 | 文字三级 |
| --dur / --ease | 220ms / cubic-bezier(.16,1,.3,1) | 动效基准 |
| --font-num | DIN Alternate / Bahnschrift | 数字专用字体 |

## 三、布局栅格

- 1920 基准：`23vw 侧栏 | 自适应 3D 舞台 | 23vw 侧栏`，头部 74px，底部 42px。
- 左右栏各 ≤4 个面板，flex 均分高度，内容溢出内部滚动。
- 面板间距 10px，内边距 12px（4px 基数）。
- <1100px：舞台置顶 46vh，面板上下堆叠。

## 四、动效红线

- ✅ 微交互 100–220ms；面板入场 350–500ms 上浮淡入；跑马灯 30–40s 匀速循环。
- ❌ 禁 bounce / elastic 缓动（廉价感）；❌ 禁 >600ms 的交互动画。
- ✅ 尊重 `prefers-reduced-motion`。
- ✅ 3D 常驻动效限三类：流光、呼吸（opacity 正弦）、相机自动巡航（可被交互打断）。

## 五、反模式清单

- ❌ 大红大紫满屏渐变、彩虹色图表（同屏图表 ≤4 种颜色 + 白）。
- ❌ 纯灰面板、无描边无角标（会变"报表"而不是"大屏"）。
- ❌ 文字直接压在 3D 场景上无底板（可读性灾难）——用带背板的 Sprite 标签。
- ❌ 单场景 >10 万三角形、>200 个独立 Mesh（用 InstancedMesh 合批）。
- ❌ 想用 ECharts/重量级库 —— 内置 DTCharts 零依赖画布图已覆盖大屏常用图形。

## 六、文案语气

- 标题：中文主标题（地点/主体 + "孪生/驾驶舱/中枢"）+ 英文全大写副标题。
- 告警：`时间 + 对象 + 事实 + 已采取措施`，如"10:31 恒温储罐 罐内温度超限，已触发联锁保护"。
- 指标带单位与趋势箭头，禁止裸数字。
